# Cookie & Crumb

A cozy, self-contained Cookie Clicker inspired browser game. Open `index.html` in a browser to play; there is no build step or dependency install.

## How to play

- Click the cookie or press **Space** to bake cookies.
- Spend cookies in the shop on helpers and upgrades that automate or multiply production.
- Pick a buy quantity, watch for a limited-time golden cookie, and come back later for offline baking.
- Your bakery saves in this browser automatically. Use the reset button in the shop to start over.

The game is built with plain HTML, CSS, and JavaScript. Google Fonts are used when the browser is online; system font fallbacks keep the game usable offline.
